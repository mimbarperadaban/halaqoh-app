# Halaqah Qur'an

Aplikasi absensi guru dan capaian hafalan Qur'an santri yang bisa dipasang di Android dan iPhone.

Repo ini hanya berisi halaman pembungkus (PWA). Aplikasi dan datanya berjalan di Google Apps Script dan Google Sheets.
Ubah `config.js` untuk mengganti URL web app atau pengaturan notifikasi.
